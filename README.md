# Praktikum PBO B2 — Java Coursework

Object-Oriented Programming practicum (PBO B2), Department of Informatics, Diponegoro University.

This repository collects the ten weekly practicum assignments, written in Java. Each folder contains the source code and exercises for that session.

## Contents

| Folder | Topic |
|---|---|
| `Praktikum 01` – `Praktikum10` | Weekly Java exercises covering classes, objects, inheritance, polymorphism, collections, exceptions, and file I/O |

## Running

Open the relevant folder in an IDE (IntelliJ IDEA / VS Code with Java extensions) and run the main class. Or compile from the terminal:

```bash
javac Main.java
java Main
```

## Notes

Coursework repository — solutions reflect the scope of each weekly assignment.
